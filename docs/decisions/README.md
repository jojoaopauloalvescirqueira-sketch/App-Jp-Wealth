# Decisões formais

Registre aqui apenas decisões aprovadas pelo gestor, uma por arquivo, com:

- data;
- título;
- contexto;
- regra aprovada;
- fórmulas e exemplos;
- impacto no Estatuto/código;
- responsável pela aprovação;
- status: provisória, em backtest ou definitiva.

Sugestão de nome: `YYYY-MM-DD-titulo-curto.md`.

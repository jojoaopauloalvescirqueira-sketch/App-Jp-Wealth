# Laboratório isolado

`contraprovas_matematicas.py` contém quatro experiências matemáticas originais,
em Python com biblioteca padrão. As primeiras três esclarecem afirmações ou
decisões didáticas discutidas nas páginas NN335, NN93 e NN225. A quarta mostra
como uma derivada correta e uma defeituosa podem ser distinguidas por diferenças
finitas. O programa não é transcrição dos exemplos do livro e não importa código
produtivo. Os resultados ficam em `validation/math-lab.json`.

Os trechos MQL5 originais do manual permanecem no Markdown, com estado
**NOT_COMPILED / NOT_RUN**. Não há EX5 distribuído neste laboratório. Essas
experiências também não integram os 36 ensaios comportamentais do harness.

Uma contraprova sobre uma afirmação matemática pode ser conclusiva nesse domínio;
ela não demonstra, por transferência, um defeito operacional no Stoikus ou uma
reprodução integral do software que acompanha os livros.

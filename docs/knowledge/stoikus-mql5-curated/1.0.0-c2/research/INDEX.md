## Identidade e estados

Os hashes completos dos PDFs constam de [source-manifest.json](source-manifest.json). [official-sources.json](official-sources.json) separa consultas oficiais posteriores. O inventário comprimido contém hashes por página, sem redistribuir o texto integral. A matriz e as notas conservam NOT_RUN para exemplos não executados. O uso de uma API ou classe no livro não demonstra sua presença no Stoikus.

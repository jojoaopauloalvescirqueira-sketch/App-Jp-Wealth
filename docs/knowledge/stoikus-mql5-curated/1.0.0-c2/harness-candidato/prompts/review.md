# Prompt review

Reveja como sessão independente. Compare contrato, diff e oráculos, sem confiar no relato do construtor. Procure vazamento de contexto, unidade trocada, evento perdido, ownership incorreto, schema futuro e recibo de outra revisão. Dê achados reproduzíveis com severidade e localização. Sem prova suficiente, INCONCLUSIVE. Não reescreva a rubrica para acomodar o resultado.

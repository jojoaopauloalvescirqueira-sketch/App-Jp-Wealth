# Prompt build

Com contrato autorizado e contexto verificado, produza primeiro um teste significativo que falha pelo motivo esperado. Implemente o mínimo dentro dos arquivos permitidos. Preserve alterações preexistentes. Rode checks apropriados e registre evidências reais. Se a plataforma exigir terminal ausente, deixe NOT_RUN. Não converta teste host em prova nativa nem habilite Supervisor.

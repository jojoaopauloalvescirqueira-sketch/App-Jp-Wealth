# Contexto por tarefa

Copiar e preencher em pasta externa de execução:

- task_id / data / operador / autorização:
- checkout raiz / revisão / alterações já existentes preservadas:
- kit versão / manifesto SHA-256 / produto / MQL / cálculo:
- pergunta ou comportamento observável, antes e depois:
- arquivos relevantes e trechos lidos com SHA-256 e linhas:
- fonte plataforma (ID, seção, página física PDF):
- fonte normativa aplicável e autoridade; se ausente, DEPENDENCY_MISSING:
- inputs confiáveis; dados externos não confiáveis; relógio e unidades:
- recursos adquiridos / proprietário / limpeza / reentrada:
- estado persistido / compatibilidade / regra para corrupção:
- dependências disponíveis e faltantes:
- testes permitidos e limites do ambiente:
- critérios de conclusão e provas que continuam NOT_RUN:

Carregar somente o contexto necessário. Um resumo antigo orienta busca, não substitui conferência da revisão atual. Preserve incertezas ao passar contexto a outra sessão.
